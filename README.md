# Coffee Survey — CS316 Project 4

## Run locally
```
npm install
npm start
```
Then open http://localhost:3000

## Pages
- `public/index.html` — Login Page (start page)
- `public/new-account.html` — New Account Page
- `public/form.html` — Form Page
- `public/records.html` — Records Page

## Data
- `data/accounts.json` — Account List (id, username, password, file for each account)
- `data/accounts/<id>.json` — Account File for each account (id, username, password, form answers)

## Deploy on Render
Build command: `npm install` · Start command: `npm start`
